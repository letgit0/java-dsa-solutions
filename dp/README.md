# 🚀 Dynamic Programming Practice Roadmap

This repository contains a structured collection of **Dynamic Programming problems in Java**, organized by pattern and difficulty progression.

The goal is to build strong DP intuition step-by-step, starting from basic recurrence patterns and moving toward advanced interview-level problems.

---

# 📌 Notes

- Focus on **patterns, not memorization**
- Every DP problem revolves around:
  - State definition
  - Choice (take / not take)
  - Recurrence relation
- Phase 1 is the most important foundation
